# workhub-coworking-landing

Bienvenido a **WorkHub Coworking**, una landing page diseñada para representar un espacio moderno de trabajo colaborativo.

Este proyecto fue desarrollado como parte de un trabajo académico enfocado en la creación de una página web estructurada, funcional e interactiva.

---

## 🌎 ¿Qué es WorkHub?

WorkHub es un concepto de coworking que busca ofrecer:

- 💻 Espacios de trabajo compartidos
- 🤝 Comunidad y networking
- 🚀 Productividad y colaboración
- ☕ Comodidad y servicios incluidos

---

## 🎯 Objetivo del Proyecto

El propósito de este desarrollo es:

- Construir una estructura web semántica con HTML.
- Aplicar estilos visuales con CSS.
- Implementar interacción básica con JavaScript.
- Manipular el DOM mediante eventos simples.
- Utilizar `alert()` para mostrar mensajes dinámicos.
- Capturar datos desde formularios.

---

## 🛠️ Tecnologías Utilizadas

- HTML
- CSS
- JavaScript

## 🚀 Cómo Clonar y Ejecutar el Proyecto

Si no tienes experiencia usando Git, sigue estos pasos:

# 🔹Opción 1: Clonar el repositorio (Recomendado)

1. Crea una carpeta en algún espacio de tu ordenador.
2. Abre Git Bash dentro de esa carpeta.
3. Ejecuta el siguiente comando:
```bash
git clone https://github.com/xDani-R/workhub-coworking-landing.git
```
4. Entra a la carpeta del proyecto:
```bash
cd workhub-coworking-landing
```
